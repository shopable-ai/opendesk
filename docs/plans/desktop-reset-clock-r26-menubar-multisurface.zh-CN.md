# Reset Clock R2.6 — macOS 菜单栏状态与多形态挂件方案

> 2026-10-14 · 状态：设计规范 / 待原生实机实施与验收 · 仓库 `shopable-ai/opendesk` · 仅 `master`
>
> 本文件是接续 R2.5 的产品/工程任务规范。**不代表以下功能已编码或通过真机验收。** 保留已批准的 R2.3 C3 主卡片视觉与 R2.5 数据真实性契约。

## 0. 专业结论与范围

**一个 Go 客户端进程、一份事实模型、一份缓存、三种显示形态：**
- **P0 顶部菜单栏状态项**（macOS `NSStatusItem`）：长期可访问、条件显示倒计时、灰态/活跃态/错误态、安全来源说明、入口菜单。
- **P0 主桌面挂件**（沿用已有 AppKit `NSPanel`）：R2.3 C3 深青绿渐变、下一次可核验未来事件、最多三条动态、历史/来源入口；默认桌面背景层，不强制置顶。
- **P1 可选迷你挂件**（同一 AppKit 进程的第二个小 `NSPanel`）：约 150–180×36–44 pt，只显示状态图形与倒计时；桌面边角或**手动放置于 Dock 周边屏幕空白**，可选悬浮于普通窗口上方。
- **P2 真正 WidgetKit 系统小组件 / Dock 图标角标**：与前面两类不同，需要分别评估；绝不拿私有 Dock/Spaces API 写进系统保留区域。

macOS 的**菜单栏位于顶部**，**Dock 默认位于底部**；Dock 左右空白不是第三方应用可注册的 Dock 插件槽位。不要尝试将文字注入 Dock 或自动占用 Dock 留白。可使用窗口浮动定位，但不保证 Dock 位置/大小不变。

## 2. 信息层级 / 交互

| 形态 | 默认 | 核心内容 | 行为 | 不放 |
| --- | --- | --- | --- | --- |
| 菜单栏 | 开 | 18pt 视觉图标、有效未来事件剩余时间（可关文字） | 点击弹出原生菜单，首项为状态摘要；入口查看主卡片、迷你卡片、详情、设置、刷新、退出 | 三条新闻、广告、伪官方倒计时 |
| 主桌面卡片 | 开 | 386pt 主卡片，已批准 C3 视觉；下次时间与最多三条常显动态 | 桌面背景层、位置锁定与点击穿透保留、可通过菜单开关 | 多个新导航/多余标题/新推广浮层 |
| 迷你卡片 | 关 | 约 150–180×36–44pt，图标 + `2h14` / `待公布` / `来源异常` | 用户开启、可拖动、记忆位置，点击打开主卡片或详情；用户手动选背景/普通悬浮 | 推广、资讯、第二套网络请求、独立设置页 |

P0 延续现有菜单，不强制再做 `NSPopover`；以后如实际用户测试证明需要，再考虑左键概览、右键菜单，但不能为了弹窗重造菜单与快捷行为。

菜单建议从上到下：状态摘要（非操作）→ 主卡片显示/隐藏 → 迷你卡片显示/隐藏（P1）→ 记录与动态 → 立即刷新 → 设置 → 免打扰 → 退出。源异常第一项给出清晰诊断，不挤占状态栏。

### 三个用户显示预设

- **标准（默认）**：菜单栏图标+文字（仅有有效倒计时时），桌面主卡片开，迷你关。
- **极简**：菜单栏状态开，桌面主卡片关，迷你关。隐藏桌面后保持可恢复入口。
- **专注监测**：菜单栏状态开，桌面主卡片按需，迷你开（悬浮为显式开关），全屏应用默认不覆盖。

设置 UI 采用一个“显示位置”区：菜单栏显示方式 `图标 / 图标+剩余时间`、主卡片显示与位置、迷你显示与位置/层级；保留原有提醒、来源、诊断设置。不允许所有可访问入口同时关闭而留下无法退出/恢复的无头后台进程。

## 3. 唯一有效的状态机：Go 生成，AppKit 展示

建议在 `internal/app` 生成一个独立的只读 `CompactStatus` / `MenuStatus` 视图数据，并放入原 `desktop.Display`；不是另一个消息源或数据库。字段可包括：
`state`、`label`、`short_remaining`、`accessibility_label`、`tooltip`、`has_verified_future`、`updated_at`。先评估最少新增字段，不复制原 `HasUpcoming` 逻辑。

| 条件（按优先级） | 菜单语义 | 主/迷你色彩 | 倒计时 |
| --- | --- | --- | --- |
| 无合法准确未来时间且来源健康 | `idle` 空心时钟 | 中性灰 | 不显示；详情写“下一次时间待公布” |
| 有且仅有通过当前既有验证和新鲜度检查的未来事件 | `upcoming` 清晰时钟 | 薄荷/蓝绿亮色 | `2h14` 或 `1d2h` |
| 上述事件在 15 分钟内 | `soon` 时钟加提醒符号 | 暖琥珀色 | `12m`；沿用已有提醒引擎 |
| 事件版本已修订且仍有效 | `revised` 状态说明/tooltip | 活跃色 + 修订符号 | **改用新时刻**，不能旧时刻继续显示 |
| 撤回/时刻过期未核实 | `withdrawn` 或 `pending_verification` | 灰 | 停止精确倒计时，不写“已恢复额度” |
| 来源过期、异常、请求无效 | `stale/error` 时钟加叹号 | 灰或强调警示 | 不从旧缓存继续提供可行动的未来倒计时 |

**第三方预测概率、历史间隔、最近已发生的重置时间，不能直接成为未来准确倒计时。** 第三方“重置已发生”不自动代表个人 Codex 账户额度恢复，也不自动变成“官方已完成”。原有 `events.Eligible` / `health.Grade` 为权威。

显示格式：长时间不显示秒；距离超过 24h 用 `1d 2h`，1h–24h 用 `2h14`，不足 1h 用 `42m`。临界时基于 UTC 实际目标时间重算，绝不保存递减计数器。仅在文字或图标状态变化时更新原生菜单栏视图，避免每秒重新布局菜单栏；现有 Go UI 秒级 tick 不能转化为不必要的菜单重绘/HTTP 请求。

**系统一致性**：Mac 菜单栏优先使用 `NSStatusBarButton.image` 模板图标/随主题变化的单色形态；根据状态调整轮廓、点、文字，而**非依赖固定红绿颜色**。图标颜色语义主要在主/迷你卡片内显示。深/浅色、增强对比度、VoiceOver、动态字号都必须可辨识；`toolTip` 和无障碍名称包含具体状态与剩余时间。菜单栏宽度不足时自动退化到纯图标，完整信息保留在点击菜单。

## 4. 窗口、Dock、Spaces、安全边界

1. **桌面主卡片沿用原生 `NSPanel` 与桌面图标层级**；避免提升到持续置顶而覆盖其他 App，保留锁定/点击穿透。
2. **迷你卡片只使用第二个轻量 `NSPanel`**；背景/普通浮动级别由用户选择，始终不越权成为系统层覆盖；默认不压住系统菜单栏/Dock，不强制进入其他 App 的全屏空间。
3. **Dock 邻近摆放为用户手动定位的近似方案**：只用 `NSScreen.visibleFrame`/屏幕安全区域防越界；Dock 移动、缩放、自动隐藏、分屏、Stage Manager、多屏后不得假设固定底边空白。没有稳定合法的公开“插入 Dock 左右空白信息”的接口。
4. **Mac 原生系统 WidgetKit** 是另一种能力：需要 SwiftUI Widget Extension、Xcode 签名/公证/App Group 数据共享及 WidgetKit 时间线；不是现有 `NSPanel`。未来可选，但受系统调度，不能承诺秒级精确常驻刷新。
5. `LSUIElement=true` 意味着默认不显示 Dock 图标；不要同时承诺菜单栏后台应用与 Dock 图标实时角标。用户选择可见 Dock 时才评估 App 激活策略变更、`NSDockTile.badgeLabel` 或自绘短状态，另列 P2 实测。
6. 不启用系统级输入监控、Dock 注入、未文档化 CGS/Spaces API 或额外辅助权限来完成小挂件。通知仍由现有 Go Reminder + 原生系统通知，避免重复的窗口级通知策略。
7. 多屏位置使用显示器身份+相对锚点或安全范围策略，拔插后回到可见屏幕；主与迷你单独存位置；休眠/唤醒重新计算倒计时，避免陈旧显示。

1. 核查 `master` 最新 HEAD、工作区修改，读取 `AGENTS.md`、R2.5 质量报告及本规范；不创建分支/worktree、不 reset/clean、不覆盖并行 Agent 产物。

3. AppKit 复用 `self.tray`、原 `makeMenu/syncMenu/apply`：用模板图标、条件倒计时文字与 tooltip，点击继续沿用已有菜单；仅对确实变化的状态更新。新菜单项调用已有 App action dispatcher，避免直接抓 HTTP。
4. 仅在必要时扩展配置字段及迁移/默认值；已有用户关闭主卡片后仍保留菜单入口；相关 demo 与 Windows 编译不回归。
5. 执行相关 Go test/race/vet/build、真实 macOS `build-macos-app.sh`、真实 `.app` 启动与菜单栏/恢复/交互截图；失败先修，不能以纯 HTML 或 Linux CI 替代 Mac 实测。

**P1（P0 真机通过后）**：
6. 同一 `native_darwin.m` 应用生命周期中按需构造 mini NSPanel；不重构主卡片；持久化显示、位置、是否悬浮。
7. 真机在不同亮度桌面、1440/4K、多屏插拔、自动隐藏 Dock、Dock 三位置、Space/Stage Manager、普通和全屏浏览器验证定位与点击。
8. 按用户主动选择增加登录自动启动。macOS 13+ 首选评估 `SMAppService.mainApp` 及实际签名包行为；没有可用签名/权限的环境不得假装该功能已完成。

**P2（独立决策，非 V1 阻塞）**：
9. 只有确有实际需求才做可选 Dock 图标角标，或 SwiftUI/WidgetKit 桌面小组件。禁止用新框架重写既有 Go UI，也不为“看起来更原生”引入第二套独立客户端。
