苹果系统中设置自动化相关的权限

1、辅助功能（Accessibility） 用于模拟点击、键盘输入、窗口控制。 路径：系统设置 -> 隐私与安全性 -> 辅助功能
2. 屏幕录制（Screen Recording） 用于抓取桌面画面/窗口内容。 路径：系统设置 -> 隐私与安全性 -> 屏幕录制
3. 输入监控（Input Monitoring）（很多自动化工具会需要） 用于监听键盘/鼠标事件（热键、回放等）。 路径：系统设置 -> 隐私与安全性 -> 输入监控
4. 自动化（Automation）（按需） 允许一个应用控制另一个应用（例如控制 Finder/浏览器）。 通常首次操作时弹窗授权。
5. 麦克风（如果录屏要带声音解说） 路径：系统设置 -> 隐私与安全性 -> 麦克风
6. 完整磁盘访问（Full Disk Access）（可选但常见） 某些日志抓取、文件扫描、脚本执行会需要。 路径：系统设置 -> 隐私与安全性 -> 完整磁盘访问
