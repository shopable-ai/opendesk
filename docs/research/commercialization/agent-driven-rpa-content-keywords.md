# Agent-driven RPA：关键词、竞品内容与 Blog 选题池

更新时间：2026-09-16

> 文档性质：Research / Content Strategy。本文用于决定后续 Blog、README、官网、视频和 SEO 内容先写什么，不是搜索量报告，也不是当前排名证明。
>
> 搜索量、CPC、关键词难度、SERP 排名和转化率本轮均未取得可靠第三方数据；本文的优先级来自产品定位、竞争直接程度、购买/解决问题意图和 OpenDesk 可提供的真实证据。

## 1. 内容总原则

所有内容围绕一条主线：

> **Computer Use 解决“Agent 能操作电脑”；OpenDesk 要进一步解决“成功一次以后，怎样变成可验证、可复用、可维护、可商业交付的 RPA”。**

内容不要分裂成几十个互不相干的产品故事。

推荐内容漏斗：

```text
Category / Thought Leadership
Computer Use → Reusable RPA
        ↓
Competitor / Comparison
Cua / Peekaboo / OpenAdapt / ADH / Codex / UiPath
        ↓
Technical Proof
Recorder / Verification / Low-token / Evidence / Repair
        ↓
Demo / Benchmark
同任务公开数据
        ↓
Commercial Proof
电商 / 客服 / 内容等真实业务案例
        ↓
Conversion
Workflow qualification / implementation / delivery runtime
```
