# SOLUTION_OPTIONS

- 更新时间：2026-04-03
- 评分范围：1-5，**分数越高越好**
- 注意：`实现复杂度` 为反向评分，**越易实现分越高**

## 1. 评估对象

本轮至少评估四条路线：

- **方案 A**：OpenCV / OCR / 区域模板匹配
- **方案 B**：截图 -> 结构化区域 -> HTML 镜像 -> 差异对比
- **方案 C**：Accessibility / UI tree 优先，CV 补充
- **方案 D**：Layout-first Hybrid（布局骨架 + OCR + HTML mirror + diff gate）

## 2. 评分维度与权重

| 维度 | 说明 | 权重 |
| --- | --- | --- |
| 可行性 | 在当前仓库与微信桌面环境中落地的现实程度 | 0.20 |
| 稳定性 | UI 变动、噪声、主题变化下的抗波动能力 | 0.15 |
| 实现复杂度 | 以最小闭环落地的难易度（高分=更简单） | 0.10 |
| 可维护性 | 长期演进、换人维护、可解释性 | 0.20 |
| 可视化能力 | 是否能自然输出可视化证据与对比 | 0.15 |
| 自动纠偏能力 | 是否便于引入 diff 驱动修正 | 0.10 |
| 回归验证友好度 | 是否便于 golden、replay、门禁验证 | 0.10 |

## 3. 方案定义

### 方案 A：OpenCV / OCR / 区域模板匹配

优点：
- 与当前仓库已有能力衔接最好
- 快速得到“能用”的元素定位
- 对特定版本 UI 可较快达成命中

缺点：
- 容易被模板漂移、主题变化、分辨率变化影响
- 缺少天然的恢复与可视化验收层
- 回归验证容易沦为“命中/未命中”二值结论

### 方案 B：截图 -> 结构化区域 -> HTML mirror -> diff

优点：
- 最符合“可测试、可回放、可纠偏”目标
- 天然适合 evidence、audit、regression
- 可作为所有后续动作的统一验收层

缺点：
- 仅靠 HTML mirror 不足以解决检测问题
- 必须搭配实际检测引擎，否则 JSON 质量不稳定

### 方案 C：Accessibility / UI tree 优先 + CV 补充

优点：
- 若可用，语义最强，能拿到控件层级与文本
- 对 HTML mirror 结构恢复很友好

缺点：
- 微信桌面端在 macOS/跨版本场景下可用性不稳定
- 依赖外部可访问性质量，不适合做唯一主线
- 一旦 tree 缺失，仍然要回退到视觉识别

### 方案 D：Layout-first Hybrid（推荐）

定义：
- 先用截图 + 布局分割得到稳定 coarse layout
- 再用 OCR / target-text / 颜色特征补结构化信息
- 再生成 deterministic HTML mirror
- 最后用 visual diff / OCR diff / region diff 作为 gate

优点：
- 兼顾可行性与可验证性
- 能复用现有 `AnalyzeLayout + OCR + screenshot` 能力
- 可持续引入反馈闭环，不依赖某一单点技术

缺点：
- 比单一路线更复杂，需要清晰 contract
- 第一轮必须克制范围，避免过早平台化

## 5. 结论

### 最终主线：方案 D

原因：

1. **最贴合项目目标**：本项目核心不是“单次识别成功”，而是“可持续恢复、可验证、可纠偏”。
2. **最契合当前仓库现实**：`page.screenshot`、`Vision.runOCR`、`AnalyzeLayout`、`AnnotateRegions` 已具备主线基础。
3. **B 是验收层，A 是感知层，D 把两者合并成闭环**。
4. **C 只适合作为机会性补充信号，不适合作为唯一主路径**。

### 具体执行策略

- **感知主线**：A 的现有 CV / OCR 能力
- **验收主线**：B 的 HTML mirror + diff
- **增强补充**：C 若在某版本微信上可用，则作为附加证据，不改变主线

## 6. Round 1 的实施边界

Round 1 不直接实现完整 D，而是只落地 D 的框架骨架：

1. 方案评分与决策落盘
2. preflight / replay / failure taxonomy / gates + evidence 建立
3. 明确 `capture -> detect -> mirror -> compare` 的最小接口
4. 为 Round 2 的最小闭环实现准备 artifact contract
