# Desktop Measurement P0–P4 Go 测试增量分类

本文件是 `docs/quality/go-test-file-classification.md` 的受审增量清单，只登记 Desktop Measurement P0→P4、Measurement 入口和 Recorder evidence 集成新增的 Go 测试。历史 151 项基线仍由主清单负责；`scripts/audit_test_architecture.js` 会把本文件追加到主清单后统一解析，因此这些行都计入现有 `## 增量登记` 之后的 reviewed rows。

所有条目都保持真实测试边界：它们依赖同包私有状态、native host source contract、package-relative fixture/helper 或产品入口装配，因此保留为 `KEEP_PACKAGE`；真实 macOS / Windows 桌面资格仍由 `tests/desktop-measurement/qualification-manifest.json` 与本地 Codex live gate 单列，不能由这些确定性测试冒充。
