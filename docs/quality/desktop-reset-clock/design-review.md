## 4. 不可抵消的质量门槛

- **G0 / 数据合法与可信**：来源许可证和真实格式清楚；若无数据，不能宣称实时公告已实现。
- **G1 / 无危险误报**：不将个人经历、赠送机会、未知时区/范围伪装成全局重置的精确时刻。
- **G2 / 请求状态真实**：HTTP 200 不等于有效数据，304 不等于上游检查；401/403 不绕过。
- **G3 / 生命周期可靠**：过期、撤回、改期和休眠不产生旧的自动通知。
- **G4 / 真桌面行为**：Mac / Windows 需要独立的真实窗口、焦点、点击穿透、显示器验证。
- **G5 / 商业证明**：真实数据成本、实际价格说明、付费试用和退款闭环均通过后才能收费。

**即使静态自评 ≥95，只要相应 G0–G5 未通过，就不能报告产品已达到 95 分。**
