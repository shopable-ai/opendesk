## R2 后续可靠性缺陷与回归证据（2026-10-12）

- **已修复：零通知结果丢失**。R2 初稿仅在 `len(due)>0` 时保存状态；免打扰、过期或来源不可用的提醒在内存里被标记已处理，但没写入磁盘，快速重启可能重新评估。现改成计划发生终结变化即保存，写失败回滚，回归测试列在 `internal/app/membership_test.go`。
- **已修复：多个数据源 ID 冲突**。自动提醒 stable key 加 `channel_id`。不同来源相同事件 ID/修订/时间不可互相覆盖。
- **已修复：历史修订偷换统计类别或原发布时间**。一个稳定事件 ID 无法从“公告预告”变成“确认完成”或“用户观察”；原始发布时间跨修订保持不变，完成声明需要独立事件；新增定时注入用例。
- **已修复：损坏历史缓存干扰基础权益**。已缓存归档额外验证，单独忽略失效归档，统计保持“数据不足”，不清除基础时钟和已消费试用 ID。
- **来源可信度纠偏**。远端 JSON 的 `official` 类型不是 OpenAI 签名，卡片显示“来源预告”；即使真实统计逻辑通过，也仍需要确认数据提供方授权与证据真实性。真实付费与商家签约仍 BLOCKED。
- **评分不作抬高**：上述是有确定复现目标的源码修复；必须等待匹配 SHA 的 CI 结果和实际原生窗口验证，再调整对应独立评分。当前 R2 暂无合法权威线上 Feed，也没有正式签名许可证服务。
