## 相比上一方案的实质修订

- 从笼统“不拆分”改为“内部子作业独立进入和评测，暂不另发第二 Skill”；默认同一 Agent，未来拆分有证据条件。
- 从偏重完整资料交接改为“正常最小记录、视图按版本生成、异常诊断按需”；必要动作前证据不等失败后补。
- 增加材料充分性按用途分级：无屏幕映射的人工截图仍可用于认识，但不能直接用于点击。
- 人工审阅、自动语义核验和格式校验分开；同版视图、纠错及影响传播成为交付职责，不自动授予操作资格。
- 明确 S9 确认业务复用要求、S10 落实应用规则，避免重复研究或循环依赖。
- 第一批不能只交 Skill 文件、HTML 或手写正确数据，必须真正完成隔离输入下的模型提取、同源审阅和纠错闭环。
- 新旧 AppProfile 的兼容与 hash 引用方向有明确规则，避免旧消费者忽略约束以及数据／审批互引造成循环 hash。
- 旧共享合同与当前验证计划的评分权重冲突已显式处理：旧权重只作为历史来源，现行评分统一引用验证计划。
