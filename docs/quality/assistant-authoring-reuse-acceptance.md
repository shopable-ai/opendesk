# AI 助手：制作与复用闭环验收合同

日期：2026-09-18。状态：DESIGN_REVIEWED；本次未运行程序、构建、模型、桌面或视觉测试。下列 NOT RUN 只表示本轮未执行，不推断仓库所有相关功能均未实现。

主方案：[AI 助手真实调用链与制作复用](../architecture/assistant-script-invocation.md)。入口合同：[会话与工作区绑定](../architecture/assistant-workspace-bindings.md)。沿用现有 G0—G7 和 F0—F10；本文的 AR 编号是需求覆盖行，不是另一套质量等级或 Flow 安装验收体系。

## 1. 三份证明不能互相代替

| 证明 | 验证对象 | 不能冒充它的结果 |
| --- | --- | --- |
| A：一次真实业务完成 | Codex/人工通过 OpenDesk 完成指定任务，动作和结果有实际证据 | 只产生计划、代码、模型完成文案或录制文件 |
| B：候选脚本可独立复用 | 冻结的普通 JS 及依赖在获准干净状态独立运行，满足预定成功标准 | Agent 临时接管补做步骤、运行中改代码、只做 mock 或复用第一次业务结果 |
| C：助手正确选择并运行 | 从用户消息到准确版本/参数/固定行为，再到共享执行服务和真实结果 | 预先选好正确函数的单测、直接调用正确路径、仅看到进程退出 0 |

Existing Assets/Recorder 入口可复用有效旧证据，不强迫重新做 A；必须注明来源及当前候选/范围为何覆盖。不能为补 A/B 重复向真实客户发送、扣款或删除，测试对象、恢复方式和副作用必须获得相应授权。

独立验证期间候选和成功标准不可改变。失败后生成新候选再验证；保留原失败。确定性 Flow 不允许 Agent 临时补救；明确声明的混合 JS/模型 Flow 则只允许合同内模型节点，并单独记录模型不确定性。

## 2. 最小真实示范集

至少使用两项核心目录外的用户资产：一项零业务参数的固定任务，一项真正读取业务参数的任务。优先低风险导出/文件操作/测试应用；至少一项不是现有 Calculator 专用接线。

两项任务均需证明新增接入无需修改 main.js 或重新编译主程序。再设置具有相似名称但对象/副作用不同的干扰候选，证明助手不是只要存在一个任务就选它。

验收记录包含：需求版本、构建来源、实际 source/entry/workdir、Flow/候选/安装摘要、测试输入或固定效果、权限和测试对象、实际命令/入口、运行身份、结果及证据。测试 expected 不进入生产输入/读值路径。

## 4. 误命中与规模评测

维护调试集与独立保留集，样本在调参前确定。覆盖正向、否定/仅解释、缺参数、相似但副作用不同、固定约束冲突、跨项目/跨会话、不可用/撤销/未激活和恶意描述符。不能只把工具描述中的正例原样作为测试题。

至少分别报告：适用候选召回率、可回答样本中的选中正确率、自动选择覆盖率、参数/固定约束一致率、应澄清时正确澄清率、错误放行数、实际业务验证通过率。全部拒绝不能换取虚假的高准确率。模型输出结构合法也不证明语义正确。

初期建议门槛：预先确定的、可回答保留样本中，候选召回和最终正确处理率各至少 95%；所有安全反例必须零错误放行。这里的 95% 是待验证的有限集合门槛，与设计 96 分不是同一指标；未确定样本规模/分层和未实际测量前不宣称达标。报告分子/分母、版本和置信区间或小样本限制。

100/1,000/10,000 描述符用于合成规模实验，记录索引修订、缓存失效、p50/p95 延迟、tokens、磁盘/内存和无权限条目不可见性。性能预算须结合固定设备和模型预先设定；不能以合成检索通过声称所有业务任务均可运行。
