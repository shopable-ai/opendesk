## 1. 三份证明不能互相代替

| 证明 | 验证对象 | 不能冒充它的结果 |
| --- | --- | --- |
| A：一次真实业务完成 | Codex／人工通过 OpenDesk 完成指定任务，关键动作和业务结果有实际证据 | 仅生成计划／代码、模型完成文案、录制文件或进程退出 0 |
| B：普通 JS 候选可独立复用 | 冻结代码和依赖，在获准测试状态通过正常执行入口运行，满足预定标准 | Agent 临时救场、运行中改代码、仅 mock、复用第一次业务读值 |
| C：助手正确选择并运行 | 请求匹配真实固定行为／参数、确定版本，再经共同执行服务得到可验证结果 | 预先选好正确函数的单测、直接调用正确路径或只验证 JSON schema |

Existing Assets／Recorder 可引用有效旧证据，不强迫重做 A，但须保留真实来源、内容版本和当前范围。不能为了补 A/B 再向真实客户发送、扣款、提交或删除。测试对象、去重／恢复方法与副作用需要明确授权；无法安全重复时只记录已完成的有限验证，B 保持未验证。

独立验证期间冻结候选和标准，失败保留原记录，修复产生新候选再验。确定性 Flow 不接受作者 Agent 临时补救。已有明确声明的混合 JS／模型 Flow 只允许其合同内节点，另测不确定性；不能借此把任意 Agent 救场归入成功。

## 2. 最小示范与测试分层

至少一条“无资产、无项目”的新制作入口，一份核心目录外固定顶层 JS，一份真正消费业务参数的自动化；再覆盖带相对资源的目录与一个无源码可运行的已安装 Flow。样本可复用同一低风险业务的不同来源，但四类入口和 A/B/C 的证据不得互相冒充。至少一项不是 Calculator 专用接线。

新增业务资产不得修改 main.js 或重新编译主程序业务分支。样本中加入名称相似但目标／副作用不同的干扰 Flow。固定脚本保持原形，不为测试便利先函数化；参数变化需验证真实输出随输入变化，不只是描述符发生变化。

每次记录需求／构建／CLI／Skill／配置版本，资产来源与摘要，实际 source/entry/Agent cwd/execution cwd/资源根／输出位置，许可和测试对象，正常执行入口，Codex 与 Execution 身份，结果及证据。expected 不进入生产输入、模型观察或读值路径。

静态文档／契约检查、确定性 CLI fixture、真实 Codex、真实 Runtime、业务结果及 UI／视觉各自记账。fixture 通过只证明相应协议／参数／状态，不证明登录、sandbox 或业务正确。生产用户行为继续采用项目规定的 JavaScript 测试，不以新 Go 测试替代正式 Runtime gate。

## 4. 匹配评测与规模边界

调试集与独立保留集分开，预先冻结样本、分层和判断标准。覆盖正向、否定／仅解释、缺参数、相似而副作用不同、固定条件冲突、跨会话／可选项目、不可用／撤销／未激活、恶意描述和加载材料。不能只重复工具描述里的正例。

分别报告适用候选召回率、可回答样本正确处理率、自动选择覆盖率、参数／固定约束一致率、应澄清时正确澄清率、错误放行数及业务验证通过率。全部拒绝不能换取虚假高准确率；JSON 合法不是语义正确。

初期有限保留集目标：候选召回与最终正确处理率各至少 95%，所有安全反例零错误放行。需要报告分子／分母、构建／模型／描述符版本以及置信区间或小样本限制。未建立并实际运行保留集前不得宣称达标。这不是下文设计评分。

100／1,000／10,000 描述符仅用于合成规模实验：测缓存失效、授权过滤、tokens、资源、p50/p95 延迟。设备与预算先固定；合成目录通过不代表这些业务都可运行，也不是当前最小闭环的前置。

本轮由同一模型依下列五种职责进行模拟反对与冲突收敛；没有调用独立评审模型，也没有真人专家、第三方审计或独立实测。五个角色不是五份独立证据。结论评价设计约束是否完整，不给未运行实现背书。

权重合计 100；得分合计 95。未解决关键实现风险必须保留为阻塞门，不能被其余项高分抵消。后续若方案实际依赖无法获得的官方能力、无法实施的授权，或必须重建执行体系，应重新降低设计评价并调整方案，而不是扩大承诺。

任一下列情况为硬否决，实施验收失败，不用总分补偿：

- 要求普通用户创建项目／Git，或每个业务脚本增加主程序接线／重复 Skill／第二 Catalog／Runtime。
- 关联即扩大读取／外发权限，发现即执行，加载未授权 hooks/config/Skills，或用 prompt 替代实际权限控制。
- 固定条件被丢弃、歧义／不可用状态错误运行、旧确认被重用、跨会话／版本／目标错绑。
- 绕过 Trust／Entitlement／原安装 owner，泄露受保护源码，修改安装树或覆盖并行源文件。
- 停止未实际收口却宣称已停，未知效果盲重试，独立验证靠 Agent 救场，未知结果假称成功。
- 清理删除用户唯一脚本、未完成接续资料或有效证据；仅 mock／读文档便宣称真实功能通过。
