# 可信示范与事实交付

## 入口与边界

对应 S3—S6。首要目标是完成真实业务并证明结果，不是在探索时硬凑最终程序。先读[共享合同](../../../../docs/frameworks/agent-to-recipe-skill-contract.md)、[AGENTS.md](../../../../AGENTS.md)和分配给本次的工作包；实际调用核对当前 [API](../../../../docs/api/README.md)。

没有实际桌面工具、权限、明确执行授权或可写的证据目录，输出阻塞；不得模拟点击、伪造 OCR 或用算术答案替代真实观察。读取 Skill 文件本身不授权运行。

## 输入

共享 request；确定版本的 TaskContract／WorkPlan；AppProfile；获准业务输入和 Secret 注入引用；当前入口／环境；本次预算和桌面操作拥有权。只读取必要秘密键，不保存值或环境全集。

已有脚本接续只在计划指出具体证据缺口时调用本 Skill，并按共享合同保留已有证据的实际作用。代码、历史日志或参考运行可以作为输入，但不能重新标注为本次 Agent 示范；如果目标是完整新生成，仍需完成本节要求的完整真实示范。

## 操作与即时留存

1. 先确认正确应用、业务对象、账号、当前页面及允许的起点；检查停止方式、权限与证据写入条件。已经存在的业务结果不能证明本次完成。
2. 每个重要节点采用“当前子目标→新观察→定位依据→动作→实际变化→验证→下一决策”。声明简短、可审查的依据，不输出或保存私有思维过程。
3. 随节点保存实际工具名与脱敏参数、before／after、预期与实际结果、pass／fail／uncertain、证据引用、分类和 retry／recovery 关联。可以引用已有工具日志，不要求全量全局录制。
4. **读到关键业务数据立即保存**：name、type、observedValue、origin、evidenceRefs、后续消费者、有效条件、Fresh Run 是否需重取。未知值不能用任务期望补齐。
5. 探索／错误／恢复与正常业务先分别标注，保留原事实；分类可以在提炼时复核，但不能删除不利证据。无新证据的相同失败不盲重试。
6. 动作可能已生效但确认失败时先核验，不能因记录缺失重复发送／提交。越权、现场身份变化、停止请求或预算耗尽时停止并保存部分包。
7. 达到业务目标后独立回读最终状态，逐项对照冻结 criterionId；验证对象身份及副作用，不以工具返回无异常代替业务成功。
8. 最后封装 dossier 和 handoff。接续中的定向补采必须把 gate scope 限于实际节点／主张；没有成功证据可以交付完整失败包，但 gate 不得为示范 pass。

## 主产物 `dossier.json`

按共享合同保存：任务／计划／应用资料引用、executionRefs、实际输入、初始／最终状态、动作索引、runtimeValues、verification、evidenceRefs、unresolved、privacy、sideEffects。

每个主张能追到当次工具输出／文件／截图等适用证据。日志、截图与业务结果优先放 `Execution.artifactDir`；交接按已登记 rootId＋相对路径引用。不能把 Runtime 不会自动产生的 scenario 工件写成“已存在”。

接续所需的来源与证据作用使用共享合同的可选元数据，不在本 Skill 重定义。定向 dossier 可以证明声明范围内的新观察；它不把范围外的参考证据升级为完整 DemonstrationDossier。

计算器示例仅说明结构：firstResult 来自本次显示区域读取；第二次表达式记录 firstResult 的消费关系；示范读到的数值是事实样本，不是以后代码的固定常量。最终应交付实际值与证据，不能抄模板中的示例。

## 消费与失败

消费者为 `procedure-synthesize`，它应仅凭合同、应用资料和 dossier 理解成功过程，不依赖本次聊天。缺关键观察时指出具体节点和待补证据。需要新应用认识返回 application-engineer；目标／权限问题返回 automation-plan。

运行结束、交接完整与业务成功分别记录；只有达到所需证据强度的完整示范 gate pass 才能进入完整新生成的正常提炼／生成路径。接续的定向 gate pass 只能支持同一声明范围内的补证、证据有界反向提炼或最小修复；其余只能诊断、定向补采或停止。

## 最小独立验收

在获准计算器任务中保存真实数据流；换无前序聊天的消费者仍可识别数据来源。删除关键证据后消费者应阻塞；中途停止仍留下已观察事实，而非事后凭记忆补造全部成功记录。
