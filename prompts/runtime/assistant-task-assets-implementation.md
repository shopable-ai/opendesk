# OpenDesk AI 助手：按任务与资产方案进入最小实施闭环

## 目标需求

让普通用户在现有 OpenDesk AI 助手中，只需提出需求，可选关联一个 JS、一个自动化目录或已安装 Flow，就能开始解释、制作／改进或使用自动化，不需要创建项目、初始化 Git 或手工配置内部工作目录。

最终用户链路：

提出需求／关联资产
→ 明确本次是解释、使用还是制作／改进
→ 在获准范围内准备材料、核对行为和参数
→ 生成可审阅候选，或经确认调用现有执行服务
→ 展示实际结果、依据和未验证项
→ 能停止，并从有效资料继续未完成任务。

本轮优先交付“任务与资产接入＋候选与接续基础＋一个已有低风险 Flow 的通用使用闭环”。不重复大范围架构讨论，不只交付规划、审计报告或新原型。完整作者工具集成按实际安全门分步接续，不为赶进度放宽现有只读通道。

## 本轮执行

沿当前实现接续，先给出简短的“可复用／需要补齐／被证据阻塞”判断，然后直接交付代码、针对性测试和同步文档。

首先打通无项目任务绑定和四类资产入口：资产可为空；单文件不默认授权父目录；目录入口不明先澄清；已安装 Flow 不要求源码。复用现有会话、TaskContract、进度、候选和运行记录，兼容旧的可选项目引用，不再造项目系统。

改进默认产生候选，原文件不动；工作资料按需准备，Agent cwd 与业务执行目录、资源及输出语义分开。保存前比较源内容变化，冲突不覆盖；未完成任务和唯一资料必须可接续、可保护。

已有 Flow 的使用接入唯一 Catalog 和正式执行服务：允许范围内选择 → 核对固定行为／实际参数 → 宿主校验与可信预览 → 确认 → 真实 Execution → 结果核验。新增业务不修改主程序业务分支。先用临时目录和低风险测试资产证明通路，不操作真实客户、发送、扣款或删除。

Codex 保持官方 harness 和薄接入方向，制作方法优先复用 Agent-to-Recipe／Human-to-Recipe。两个通用 Skill 与运行配置均不授予权限；不按每个脚本生成重复 Skill。实际需要进入作者集成时，再核验当前官方版本、配置来源和工具机制；文件／工具授权、来源隔离及联合停止未通过前，不开放真实作者动作，不以移除限制假装接通。

在现有助手中显示任务、关联资产、实际影响、进度和结果；阻塞及未知不能藏在技术详情里。无需先重做完整 UI 或强制实现三套卡片。模型声明、工具实际事件和业务验证分别呈现，不能合并为一个成功标志。

发现失败后沿失败链定位、最小修复、重新验证。当前环境不能运行的 Codex／Runtime／桌面项目如实标记 NOT RUN 或 BLOCKED，仍完成可独立交付的代码与测试资产，并给出基于真实差距的本地验收交接。

## 完成标准

- 四类入口都能表达和持久化任务／资产；不要求 projectId，已有可选项目记录不丢失。问答和确定 Flow 运行不强制建立制作目录。
- 解释与发现零业务执行；单文件越权读取被实际控制拒绝；目录歧义、缺资源、固定条件冲突、不可用和未激活状态均不错误运行。
- 候选可审阅、可另存、可接续；原文件保持不变；并行修改报冲突；相对依赖、业务执行目录和输出含义不被任务目录悄悄改变。
- 至少一个核心目录外、非 Calculator 专用接线的已安装低风险 Flow，经助手确认后进入现有执行服务；取得实际运行身份与结果。只有 fixture 的环境不得把该项标为真实 PASS。
- 已明确选择且自身无模型依赖的 Flow，不因 Codex 不可用而被人为阻止从原 Runner／CLI／计划中心入口运行。
- 旧确认、重复确认、跨会话事件、内容变更、权限撤销均不会错误放行。停止同时覆盖模型调用和实际动作；未收口保持 stopping，未知效果不自动重试。
- 明确区分第一次业务完成、候选生成和候选独立验证；测试时不靠 Agent 临时救场，不把模型结束或退出 0 当作业务成功。
- 清理不会删除用户唯一脚本、未另存候选、未完成接续资料或有效证据。受保护源码不因解释、改进或日志而泄露。
- 输出真实修改、测试结果、证据和剩余缺口；静态、fixture、真实 Codex、Runtime、业务及视觉分别记账，沿既有验收编号记录，不批量把未运行项改成 PASS。

## 必要边界

- 沿用 master；不创建新分支，不 reset，不 force push。写入前重新确认当前版本和目标内容，保护并行修改，不把其他会话提交算作本轮成果。
- 只复用既有 Flow 安装、信任、权益、Catalog 与 Execution；不新建平行能力目录、Runtime、业务脚本副本或通用 Agent 编排平台。
- 作者态与使用态权限分开；Skill、profile、目录关联、模型判断和图示均不能替代宿主与实际工具授权。第三方 AGENTS、Skills、hooks、配置不因关联而自动获得信任。
- 不强制已有脚本函数化、参数化、源码迁移或安装；参数必须由实际代码消费。不得修改 Flow 安装区或绕开受保护载荷边界。
- 可复用成果从真实缺口接续；不得用降低断言、伪造证据或抬高评分满足目标。需要独立评审时如实说明工具是否可用，没有则标注模拟评审。
