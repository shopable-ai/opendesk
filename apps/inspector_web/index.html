How the four local inspection steps work
  1. Connect to OpenDeskOpen the target first, then connect this page.
  2. Choose the target windowMatch its application and exact window title.
  3. Open that windowOpen scope creates a temporary read-only connection.
  4. Click a row in UI treeThe tree is below on small screens and left on desktop; ↻ refreshes it.

Target windowThe desktop app or separate browser window you want to examine.

ScopeA temporary read-only connection to that exact native window. It does not click or type.

UI treeThe controls and text exposed through macOS AX or Windows UIA. Click a row to see its properties.

One OpenDesk app: OpenDesk serves this page, its launch control, and the read-only Inspector API from the same current Framework Runtime origin. Do not start a Python server or companion OpenDesk process.

One client: One OpenDesk process accepts one connected Inspector; a second Connect is rejected until the first closes, revokes, or expires. LAN access must be enabled explicitly from the macOS Developer tray menu.

Web target: Use a separate native browser window, not another tab in this Inspector window. Refreshing the UI tree never captures pixels; use Capture visual only when you need a short-lived reference.
