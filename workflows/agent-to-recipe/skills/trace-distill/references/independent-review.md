# trace-distill 独立 Skill 审查基线

## 目的

用于审查 trace-distill 是否能够独立完成 Agent 执行轨迹到必要步骤的提炼。

本文件不是新的 Workflow 阶段，不改变 S7 定义。

## 核心判断

输入：

```
Raw Trace
+
Demonstration Dossier
+
实际观察、结果、运行时值证据
```

处理：

```
retain
merge
omit
recovery
```

输出：

```
DistilledSteps
```

## Calculator 审查要求

必须解释：

### firstResult 读取

不能删除。

原因：

```
第一次计算结果
      ↓
第二次计算输入
```

这是实际运行时数据关系。

### 清空动作

不能因为最终代码没有出现就自动删除。

必须判断：

- 是否影响状态准备。
- 是否影响重复执行。
- 是否有实际证据证明可省略。

### 连续数字输入

不能简单按动作数量去重。

需要区分：

- 用户业务步骤。
- Runtime 键盘事件。

## 独立验收问题

必须回答：

1. 原始事实来自哪里。
2. 每个保留步骤对应哪些 source action。
3. 为什么删除某个动作。
4. 运行时值由谁生产、谁消费。
5. 失败时返回事实采集、应用认识还是步骤提炼责任。

禁止：

- 从最终 JS 反推历史 Agent 行为。
- 用代码结构替代执行证据。
- 用测试通过替代方法正确。
