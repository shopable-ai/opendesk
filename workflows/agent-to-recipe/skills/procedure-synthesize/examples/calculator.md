# procedure-synthesize 示例：Calculator 业务过程

> 目的：展示如何把必要路径转为业务过程和数据关系。

## 输入

固定 DistilledSteps。

不重新读取 Raw Trace 判断动作取舍。

## 业务关系

关键运行时值：

```
firstResult
```

生产者：

```
第一次计算后的实际 UI 读取
```

消费者：

```
第二次计算输入
```

允许转换：

```
character expansion
```

不是：

```
重新计算
```

不是：

```
替换成固定110
```

## 输出示例

Business Step：

```
读取第一次计算结果
→ 保存运行时值
→ 第二次计算消费该值
→ 读取最终结果
```

## 边界

一次观察值不能自动成为未来默认参数。
