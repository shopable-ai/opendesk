# application-engineer 示例：Calculator 应用认识

> 目的：展示 application-engineer 如何工作，不定义 Calculator 专用规则。

## 输入

用户任务：

> 使用计算器完成两次计算，第二次计算需要使用第一次真实读取结果。

进入本 Skill 时未知：

- 当前是否已经打开目标应用；
- 应用当前模式和状态；
- 输入控件如何定位；
- 结果区域是否可可靠读取；
- 当前环境是否支持所需操作。

不能从未来生成的 JavaScript 反推出这些事实。

## 处理

应用认识的目标不是收集全部界面信息，而是回答当前任务继续执行所需的问题：

1. 哪个应用承担任务；
2. 哪些区域负责输入和结果读取；
3. 如何确认目标对象属于当前任务；
4. 哪些条件不足，需要继续观察或停止。

## 输出示例

形成限定范围的应用认识：

- application identity：当前目标计算器；
- required targets：输入按钮、结果显示区域；
- required operations：输入、读取、状态准备；
- limitations：当前认识只支持已观察环境。

## 错误示例

错误：

> 直接读取 calculator-current.js，得到 width=232、height=321，因此 S2 已完成。

原因：

这些属于已有实现或验证环境中的规则，不是首次应用认识的来源。

正确关系：

任务需求
→ 必要认识
→ 观察
→ AppProfile
→ 后续规则与代码。
