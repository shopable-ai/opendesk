# application-engineer｜失败处理与返回

## 先安全停止，再归因

保存原 request、输入版本、原失败/回执、最后可信状态、已知副作用和真实局部成果。动作可能已经发生而效果 unknown/partial 时，停止依赖输入，先在授权内查实际效果；不盲重放、不切换 backend 重复提交、不声称取消能撤回原生动作。没有新证据的同类失败停止重试，跨子作业累计预算。

已存在但漏交的获准资料先向协调者补交；确实缺失/冲突才返回原责任。资料不足不证明规则错误，业务失败也不自动等于定位失败。

## Agent 来源路由

| 失败/缺口 | 返回责任 | 必须附带的具体内容 | 恢复条件 |
| --- | --- | --- | --- |
| 目标、授权、成功条件或复用政策不明确/改变 | S1/原需求或政策负责人 | 冲突原文、受影响动作、待确认项 | 新确认版本与授权已交付 |
| 历史动作、实际读值/回执缺失或互相矛盾 | S3—S6 task-demonstrate | 缺哪个动作/读值、来源矛盾、可补证问题 | 取得原证据或明确新的补采记录，不能回填旧历史 |
| 原动作取舍、必要准备/读值被删 | S7 trace-distill | 原 action、依赖及错误 disposition | 新 DistilledSteps 或有据复用结论 |
| 业务含义、参数、变换/数据关系、业务分段错误 | S8—S9 procedure-synthesize | 受影响步骤/值及业务依据 | 已确认过程新版本；不在 Profile 偷改 |
| 应用身份/关系、定位、读取、等待或动作规则不足/失效 | 本 Skill 的适用模式（S2/S10） | 原 Profile/规则、目标、观察差异、影响范围 | 补认识或局部规则，完成所需重验 |
| JS/API 使用、控制流、参数传递或异常处理错误 | S11 recipe-build | 源码位置/步骤映射、实际失败、正确规则引用 | 新 Candidate 与适用重验 |
| Oracle、场景、证据收集或资格范围错误 | S12 recipe-qualify | 冻结候选/标准、缺失证据、越界声明 | 按原标准重新核验，不降低标准 |
| 资料版本/hash/根目录不可核对、输入漏交 | 协调者 | 精确 ref、缺字节/权限/版本、受影响消费 | 固定资料可读且一致 |
| 现场身份/权限/预算不足、Runtime 能力缺口 | 协调者/相应环境或 Runtime owner | 所需能力/授权、已检查事实、停止点 | 取得真实能力或获准替代；不发明接口 |

## Human 与专项问题

Human 来源不改标 Agent 示范：事实回 H2 并按需 H4 补观察/审阅；归组回 H3/H4；意图/需求回 H4、过程/应用工程回 H5；代码回 H6；验收回 H7；授权/目标回 H1。保留原来源和原合同，不把所有问题统一退 H4/H5。

CollectionProfile drift/item boundary 冲突由本 Skill 修 Profile；continuity/mutation 保留 partial/evidence，返回 collector/现场变化对应责任，禁止 text-only 去重硬拼。业务字段映射交过程/业务 parser；分页/加载更多不擅自塞入 Profile。必要 VLM 不可用则 blocked；非必要 assist 缺失且确定性结果满足要求时可继续该限定范围，并记录未调用。

## 失败返回的最小内容

在既有 handoff/nextRequest 中表达：原 task/plan/mode/scope；精确输入/方法版本；状态和失败证据；已完成的真实局部成果；哪些主张失效/仍有效；已知副作用；阻塞哪些消费者；返回责任；缺哪项资料/规则；下一安全动作；剩余预算和重验范围。不得只写“需要更多上下文”。这不是新 Failure schema。

fail 表示已有反证，blocked 表示必要条件不足，not-run 表示没有执行相应验证。保留未知和 partial，不把它们装成成功路径；可交付只读认识但不能把原操作请求缩小后称整体 pass。

## 维修与复用

规则修改采用新 revision，记录旧/新字段及依据，按 dependsOn 传播影响；依赖不明则保守复核。先冻结新 Profile/helper，再生成同版审阅/验证和 handoff。旧记录只证明旧版和旧范围。

方法/输入/合同及适用现场条件均未变化时，复核后可以复用旧字节和原范围；任一影响性变化都不得沿用原通过标签。候选受影响则交 S11 更新并由 S12 重验；本 Skill 不发布候选资格。新观察、新执行和新尝试分别保留，不覆盖先前失败或资格。
