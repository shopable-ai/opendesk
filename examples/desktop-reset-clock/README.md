# Desktop Reset Clock

**状态：设计阶段 / PROPOSED。当前目录没有可运行程序。**

拟在 OpenDesk 仓库内开发一个独立 Go demo：**中心服务器定时获取指定 X 账号的内容，提取并审核 Codex 公共重置公告，通过共享 feed 分发给 macOS / Windows 桌面端。**客户端显示当前时间、换算时区、展示公告并提醒。

用户要求先确认整体方案，再写代码。当前只有文档，没有 Go module、服务端、UI、真实采集、安装包、支付接入或运行通过记录。

## 产品边界

- 公告与个人额度分别表达，公开帖子不能证明每个账户已恢复。
- 统一重置、赠送可使用的重置机会、规则变化和倍率活动分别分类。
- 没有确定时间时显示待确认，不编造下一次倒计时。
- 桌面端只读本产品 feed，不携带 X / 模型密钥，不重复抓取源站。
- 个人 Codex 额度读取是可选后续功能，不要求安装 CLI 才能接收公告。
- 0.99 币种及准确 tibo 账号待确认；年度一次支付、30 天试用均为建议。

## 获准实施后的目录原则

在本目录创建独立 Go module，两个预期入口为：

- cmd/reset-clock-server/：增量采集、审核、事件发布及后续权益。
- cmd/desktop-reset-clock/：桌面、时间、feed 校验和提醒。

事件契约可共享；服务端不能引入桌面 GUI 依赖。Go 管理业务规则，平台适配允许少量原生调用。原生卡片优先，设置窗口可选 Wails，版本经验证后确定。

当前不修改 OpenDesk Runtime、Browser RPC 白名单或根 module；不因为存在本目录就加入可运行示例 catalog 或默认发行包。它不是现有 JavaScript App Mode package，不能用 opendesk -script 运行。
