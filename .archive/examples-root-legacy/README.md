# Retired examples-root artifacts

These files were removed from `examples/` while converting the public Examples tree to canonical domain directories for `apps/example-explorer/`.

They are retained only when they still provide historical implementation or diagnostic context. They are not supported public examples, are not part of the Example Explorer catalog, and should not be used as current commands.

The `image-layout/` group contains older real-application/layout experiments that relied on ad-hoc desktop state, placeholder paths, Node assumptions, or legacy output locations. Current maintained layout tooling lives in `tests/automation/tools/image-layout-lab/`.
