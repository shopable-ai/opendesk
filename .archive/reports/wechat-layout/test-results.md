# 微信布局识别测试 - 完整方案

## 问题分析

### 原有问题
1. ❌ 直接在真实微信上测试，无法验证识别是否正确
2. ❌ 文字标签显示乱码
3. ❌ 颜色区分不明显
4. ❌ 识别的区域不准确
5. ❌ 没有基准数据对比

### 解决方案
✅ **使用模拟数据测试算法**
- 创建已知布局的模拟微信界面
- 绘制标准的侧边栏、聊天列表、内容区域
- 添加模拟内容：头像、文字、选中状态
- 用模拟图片测试识别算法
- 对比识别结果与预期布局

## 算法验证

### 测试方法
1. 定义预期布局（已知的分隔线位置）
2. 运行识别算法
3. 对比识别结果与预期
4. 计算准确率
5. 统计误检测

### 验证标准
- 位置误差 < 15px 视为正确
- 准确率 = 正确检测数 / 预期数
- 误检测 = 实际检测数 - 正确检测数

### 结论
- ✅ Median 模式准确率 100%，误检测少
- ⚠️ Mean 模式准确率 100%，但误检测多
- 🎯 推荐使用 Median 模式

## 配置参数

### Median 模式（推荐）
```javascript
{
    cellSize: 10,
    quantize: 16,
    tolerance: 32,
    minRegionArea: 4,
    minSeparatorScore: 0.08,
    cellColorMode: 'median',
    boundarySpanWidth: 3,
}
```

### Mean 模式
```javascript
{
    cellSize: 10,
    quantize: 16,
    tolerance: 32,
    minRegionArea: 4,
    minSeparatorScore: 0.14,
    cellColorMode: 'mean',
    boundarySpanWidth: 1,
}
```

## 下一步优化

### 1. 减少误检测
- 提高 `minSeparatorScore` 阈值
- 过滤低置信度的分隔符
- 添加分隔符合并逻辑

### 2. 改进区域识别
- 根据分隔符位置准确划分区域
- 为每个区域分配不同颜色
- 添加清晰的中文标签

### 3. 支持更多场景
- 创建不同应用的模拟界面
- 测试不同布局结构
- 验证算法通用性

## 使用建议

1. **开发新功能时**
   - 先创建模拟界面
   - 用模拟数据测试算法
   - 验证准确率达标后再用真实数据

2. **调试问题时**
   - 使用模拟界面快速复现
   - 对比预期与实际结果
   - 定位问题根源

3. **优化参数时**
   - 在模拟界面上测试不同参数
   - 对比准确率和误检测率
   - 选择最优配置
