# 微信布局可视化 - 使用说明

## 快速使用

```bash
# 在项目根目录运行
./testMonkey-go -script tests/wechat/wechat_visualization.js
```

## 可视化特性

### ✅ 彩色区域标记
- 每个识别的区域使用不同颜色
- 半透明覆盖层，保持内容可见
- 自动分配颜色

### ✅ 中文标签
- **侧边栏** - 左侧导航区域
- **聊天列表** - 中间聊天列表
- **内容区域** - 右侧内容显示
- **工具栏** - 顶部工具栏

### ✅ 分隔符标记
- 红色线条 - 垂直分隔符
- 蓝色线条 - 水平分隔符

## 注意事项

1. **运行前确保微信已打开**
   - 微信桌面版需要处于可见状态
   - 不能最小化

2. **脚本执行时间**
   - 大约需要 8-10 秒
   - 包括截图、分析、生成可视化

3. **输出文件位置**
   - 固定在 `.runtime/tests/wechat/` 目录
   - 每次运行会覆盖之前的文件

## 对比两种模式

### Median 模式
- 检测更多分隔符和区域
- 更细致的区域划分
- 适合详细分析

### Mean 模式
- 检测较少分隔符和区域
- 更简洁的区域划分
- 适合快速概览

## 技术实现

- **纯 JavaScript** - 无需编译
- **Vision API** - 原生布局分析
- **自动标注** - 智能识别区域类型
