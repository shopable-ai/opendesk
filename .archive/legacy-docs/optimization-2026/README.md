## 🎓 讨论方法论

### 评分算法
```
总分 = Σ(维度分数 × 权重) × 实施可行性系数

权重分配:
- 架构设计: 25%
- 代码质量: 20%
- 性能优化: 15%
- 可维护性: 15%
- 安全性: 10%
- 文档完整性: 10%
- 测试覆盖率: 5%
```

### 讨论规则
1. **正方**: 提出方案 + 论证优势 + 实施路径
2. **反方**: 识别风险 + 提出反例 + 质疑可行性
3. **门禁**: 问题定义 + 量化目标 + 实施步骤 + 风险评估
4. **证据**: 代码示例 + 性能数据 + 对比分析

### 停止条件
1. 总体评分 >= 95分
2. 连续5轮提升 < 0.5分
3. 所有P0问题已解决
4. 所有方案有可追溯文档
5. 反方无法提出新的重大风险
