# EXECUTION_RUNTIME_NOTES

## 目的

保存运行期的短笔记、观察项和临时环境信息。

这不是失败案例库，也不是完整日志转储。

这里适合记录：

- 当前窗口布局特征
- 多屏/负坐标情况
- 是否存在人工干预
- 某轮运行使用的关键 artifact
- 需要下轮验证的观察点

不适合记录：

- 大段控制台输出
- 每一次重复重试
- 没有结论的流水账

## 推荐写法

```text
### [日期] 运行笔记

- runId:
- 环境特征:
- 关键观察:
- 关联 artifact:
- 下一轮关注点:
```

## 当前约定

- 高价值、可复用的问题，转入 `docs/EXECUTION_FAILURE_CASES.md`
- 普通运行日志继续保留在 artifact / terminal 输出，不抄录到文档
- 临时运行观察可先写在本文件，确认可复用后再升级成 failure case
